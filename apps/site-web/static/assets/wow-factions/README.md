# World of Warcraft faction emblems

Blizzard's original Horde symbol and Alliance lion, not traced/recreated icons.
The high-resolution transparent sources were downloaded from Warcraft Wiki on
10 November 2026. The file pages credit Blizzard's **World of Warcraft 5 Year
Anniversary: BattleCry** PSD artwork.

| Asset | Source page | Original image |
| --- | --- | --- |
| `horde-{64,128}.webp` | https://warcraft.wiki.gg/wiki/File:HordeLogo.png | https://warcraft.wiki.gg/images/HordeLogo.png |
| `alliance-{64,128}.webp` | https://warcraft.wiki.gg/wiki/File:AllianceLogo.png | https://warcraft.wiki.gg/images/AllianceLogo.png |

Original Blizzard campaign (archived):
https://web.archive.org/web/20100207205430/http://www.worldofwarcraft.com/wowanniversary/battlecry/

Processing: cropped transparent margins, aspect-preserving Lanczos downsampling
to fit 64×64 and 128×128, then lossless WebP compression with alpha preserved and
metadata removed. No recolouring, glow, shadow or other effects added. Sources
are raster, so no invented SVG tracing is substituted. Display is 16×18 CSS pixels
with `object-fit: contain`; assets are served locally, never hotlinked. Unknown
factions render no image.
