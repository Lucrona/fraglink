Privacy

What Fraglink reads

The list of running programs (to recognise games), launcher install lists (Steam, Epic, GOG) and how long since you last used the mouse or keyboard. It never reads game memory or what you type, so it is safe with anti-cheat.

Nothing leaves this PC unless you sign in under Account. Invisible status shows you as offline to friends.
