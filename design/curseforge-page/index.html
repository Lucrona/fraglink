Fraglink /played

by Fraglink · 1.1.0

Saves Retail and WoW Forever /played on your PC for Fraglink. Uploads only add time and never lower your hours.

Retail 12.1.5Retail 12.1.7Forever 1.60.1

Description

Fraglink /played saves each character's /played time on your PC. You upload that file at playfraglink.com. The addon does not send anything while you are in game.

It is one addon for Retail and WoW Forever. When you log in, it asks the game for /played and marks the saved file Retail or Forever.

An upload only adds time. A file with a lower total is refused, and the hours already stored are left as they are. Retail and Forever stay separate.

Install

  1. Download the zip.
  2. Unzip it into World of Warcraft/_retail_/Interface/AddOns and World of Warcraft/_forever_/Interface/AddOns. Each should contain a FraglinkPlayed folder.
  3. Restart the game, or type /reload. Enable Fraglink /played on the addon list if it is off.

Use

  1. Log in to each character once. Type /reload or log out so the game writes the file.
  2. On playfraglink.com, open the WoW page, pick Retail or Forever, and upload WTF/Account/<ACCOUNT>/SavedVariables/FraglinkPlayed.lua.
  3. Link Battle.net so a Retail character can be verified. Forever characters stay unverified until that check is turned on. The file on your PC is kept either way, so you can upload it again later.

A line in chat says when a character was recorded. /fragq hides that line.
